# Analisador Sintático em Bison
Este projeto implementa um **Analisador Sintático** utilizando as ferramentas **Bison** e **Flex**. O executável gerado exibe a árvore sintática correspondente à entrada fornecida, permitindo a visualização da estrutura do código analisado. Tokens com atributos variados são explicitados na árvore, garantindo que identificadores e valores numéricos sejam claramente representados.
